# Re:Turn（デモ）

災害後 建物再入場確認アプリ

災害発生後、建物内へ再入場してよいかを現場で確認するための研究発表用スマートフォン向けWebアプリのデモです。

⚠️ 実際の建物安全性を保証するシステムではありません。

## 技術構成

- React + TypeScript + Vite
- Tailwind CSS v4

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで表示された URL（例: http://localhost:5173 ）を開いてください。
PCブラウザではスマートフォン幅で中央表示されます。

## ビルド

```bash
npm run build
```

## 画面構成

1. ホーム画面 - 建物情報・ガス漏れ警報器の状態表示、確認開始
2. チェックリスト画面 - 回答内容に応じて次の確認項目を動的に切り替え、「はい / いいえ / 判断できない」で回答
3. 判定結果画面 - Routine Check / Targeted Check / Expert Review / HOLD
4. 専門家への確認依頼画面 - 相談内容の自動整理と送信（デモ）

## デモ用機能

ホーム画面下部の「研究用デモ操作パネル」から、ガス漏れ警報器の状態（正常⇄警報）を
切り替えられます。警報状態では、チェックリストの回答に関わらず必ず「再入場しない」と判定されます。

### チェックリストの動的分岐

最初は建物の傾きから確認を開始し、回答内容に応じて次の項目を追加します。
構造上の懸念があれば隣接建物・地盤、非常経路の懸念があればエレベーター・電力、
火災設備の懸念があれば天井・ガラスを確認します。
実運用では建物カルテ・立地・災害種別などを含め、専門家と定義したルールを利用してください。

### デモケース

- ケース1（Routine Check）: 7項目すべて「はい」・警報器「正常」
- ケース2（Targeted Check）: 「室内の落下物」などを追加し、天井・ガラス・電力を「いいえ」または「判断できない」
- ケース3（Expert Review）: 構造・モニタリングなどを「判断できない」＋コメント入力 → 専門家への相談画面で内容が自動生成される
- ケース4（HOLD）: 構造、非常階段、ガス、火災、閉じ込め、重要データのいずれかを「いいえ」、またはガス警報器を「警報」に切替
