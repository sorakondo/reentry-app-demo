# 災害後 建物再入場確認（デモ）

災害発生後、建物内へ再入場してよいかを現場で確認するための研究発表用スマートフォン向けWebアプリのデモです。

⚠️ 実際の建物安全性を保証するシステムではありません。

## 技術構成

- React + TypeScript + Vite
- Tailwind CSS v4

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで表示された URL（例: http://localhost:5173 ）を開いてください。
PCブラウザではスマートフォン幅で中央表示されます。

## ビルド

```bash
npm run build
```

## 画面構成

1. ホーム画面 - 建物情報・ガス漏れ警報器の状態表示、確認開始
2. チェックリスト画面 - 5問に「はい / いいえ / 判断できない」で回答
3. 判定結果画面 - 再入場可能 / 再入場しない / 専門家による確認が必要
4. 専門家への確認依頼画面 - 相談内容の自動整理と送信（デモ）

## デモ用機能

ホーム画面下部の「研究用デモ操作パネル」から、ガス漏れ警報器の状態（正常⇄警報）を
切り替えられます。警報状態では、チェックリストの回答に関わらず必ず「再入場しない」と判定されます。

### デモケース

- ケース1（安全）: 5項目すべて「はい」・警報器「正常」→ 再入場可能
- ケース2（危険）: いずれか1項目を「いいえ」→ 再入場しない
- ケース3（判断不能）: いずれか1項目を「判断できない」＋コメント入力 → 専門家による確認が必要 → 専門家への相談画面で内容が自動生成される
- ケース4（ガス警報）: デモ操作パネルで警報器を「警報」に切替 → 再入場しない
